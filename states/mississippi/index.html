Forming a company in Mississippi

What Mississippi charges to form an LLC or corporation, what you file each year, and where to file it. Fees last reviewed 2026-10-11.

Fees at a glance

Mississippi state fees
LLC to form$50
LLC to keep each year$0 a year
Corporation to form$50
Corporation to keep each year$25 a year
Report dueApr 15
Registering an out-of-state company here$250 (LLC), $500 (corporation)

Yearly cost is the report fee plus any minimum tax owed no matter how much you earn. Taxes that grow with revenue or shares aren't included.

Filings for an LLC

  • File Articles of Organization with Mississippi $50 state fee
    This is the filing that creates the company. File online with the Mississippi business filing office.
  • Mississippi annual report Free/yr
    Apr 15. No fee, but you still have to file. If you miss it, the state can dissolve the company.

Filings for a corporation

  • File a Certificate / Articles of Incorporation with Mississippi $50 state fee
    This is the filing that creates the company. File online with the Mississippi business filing office.
  • Mississippi annual report $25/yr
    Apr 15. If you miss it, the state can dissolve the company.
